# Pedidos de rascunho — pasta de revisão

Somente arquivos JSON revisados e autorizados podem ser colocados aqui em um bloco futuro.

O workflow FWB-03 exige caminho editorial/fwb/requests/<slug>.json, identificador estável
de operação (operation_id) e SHA-256 dos bytes aprovados. Ele só admite criar ou editar
rascunhos, nunca publicar. Não inserir credenciais, dados sensíveis, status=publish ou
outros campos administrativos.

Nenhum pedido editorial real faz parte do FWB-03.
